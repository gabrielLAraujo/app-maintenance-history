# Créditos das imagens dos dados de exemplo

As fotos usadas pelo botão "Carregar dados de exemplo" vêm do [Wikimedia Commons](https://commons.wikimedia.org/), com licenças livres. Foram baixadas na largura de 1600 a 1920 px; o app as reprocessa como qualquer upload (remove metadados, converte para sRGB e recomprime), sem outras alterações. Só a foto do carro é de um Honda Civic da mesma geração (1996–2000); as demais mostram peças e serviços de outros veículos, como ilustração.
